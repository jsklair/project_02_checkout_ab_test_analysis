# Project 02: Checkout Conversion Experiment

## Overview

This project analyses a synthetic A/B test of a redesigned e-commerce checkout.

The aim is to determine whether the redesigned checkout improves conversion sufficiently to justify rollout, while also considering commercial value and technical payment-error risk.

## Project status

In development.

## Planned analysis

- experiment quality and balance checks
- checkout conversion analysis
- revenue per checkout user
- technical payment-error guardrail
- statistical significance and confidence intervals
- subgroup analysis where useful
- final rollout recommendation

## Tools

- SQL
- Python
- Git and GitHub

## Data

The dataset used in this project is synthetic. It is designed to represent a realistic checkout experiment and should not be interpreted as data from a real company.
